# Jala Asadli Personal Website

This repository contains the **personal website** of Jala Asadli, a third-year IT student at ADA University. The website showcases my education, hobbies, projects, and ways to connect with me professionally. It is built using **HTML and CSS**, with beginner-friendly styling based on Week 03 learning outcomes from my web development course.

## Features

- Responsive layout that adapts to different screen sizes.
- Home page with introduction, profile picture, and social links.
- Educational background section with lists of achievements and programs.
- Navigation menu to explore different pages.
- Hover effects on profile pictures and navigation links.
- Styled lists, headings, and horizontal rules for readability.

## Pages

1. **index.html** - Home page with personal introduction and images.
2. **education.html** - Education and academic achievements.
3. **contact.html** - Contact form to reach out.
4. **weekly_schedule.html** - Overview of weekly schedule.
5. **questionaire.html** - Survey/questionnaire for visitors.

## Technologies Used

- **HTML5**
- **CSS3**
- Google Fonts for custom typography.
